# 📦 Estoque Fácil

Sistema simples de controle de produtos desenvolvido em Python, como parte do processo de aprendizagem de lógica de programação.

O projeto permite listar, cadastrar, atualizar e excluir produtos por meio de um menu interativo executado no terminal ou no Google Colab.

## 🎯 Objetivo do projeto

Praticar os principais conceitos da linguagem Python por meio da construção gradual de um sistema de controle de estoque.

## ⚙️ Funcionalidades

- **Listar produtos:** exibe os produtos cadastrados.
- **Cadastrar produto:** adiciona um novo produto à lista.
- **Atualizar produto:** altera o nome de um produto existente.
- **Excluir produto:** remove um produto da lista.
- **Menu interativo:** permite escolher as operações disponíveis.
- **Encerrar o sistema:** finaliza a execução quando o usuário escolhe a opção `0`.

## 🧠 Conceitos de Python utilizados

- Variáveis e tipos de dados.
- Listas (`list`).
- Entrada e saída de dados com `input()` e `print()`.
- Estruturas condicionais (`if`, `elif` e `else`).
- Estrutura de repetição (`while`).
- Percorrendo listas com `for`.
- Verificação de elementos com `in`.
- Manipulação de listas com `append()` e `remove()`.
- Seleção de opções com `match/case`.

## 💻 Tecnologias

- Python 3.10 ou superior.
- Google Colab.
- Git e GitHub para versionamento e publicação do código.

## ▶️ Como executar

### Opção 1 — Google Colab

1. Acesse o [Google Colab](https://colab.research.google.com/).
2. Crie um novo notebook.
3. Copie o código Python deste repositório.
4. Cole o código em uma célula.
5. Execute a célula e escolha as opções do menu.

### Opção 2 — Python instalado no computador

1. Instale o Python 3.10 ou superior.
2. Salve o código em um arquivo chamado `estoque_facil.py`.
3. Abra o terminal na pasta do arquivo.
4. Execute:

   ```bash
   python estoque_facil.py
   ```

## 📋 Menu do sistema

```text
=== ESTOQUE FÁCIL ===
1 - Listar produtos
2 - Cadastrar produto
3 - Atualizar produto
4 - Excluir produto
0 - Sair
```

## ⚠️ Limitações da versão atual

- Os produtos ficam armazenados em uma lista na memória.
- Os dados não são preservados quando o programa é encerrado.
- A atualização remove o produto antigo e adiciona o novo ao final da lista.
- O sistema ainda não utiliza banco de dados nem interface gráfica.
